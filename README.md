# Shift-Helper

Shift-Helper автоматизирует рабочие книги сменного персонала Кочубеевской ВЭС и
формирование утреннего рапорта.

## Текущая архитектура

- **LibreOffice Calc** — рабочий табличный интерфейс оператора;
- существующая книга журнала событий — первичный рабочий документ;
- **Python Shift-Helper Core** — проверка, нормализация, отбор данных и генерация
  новых `.xlsx`-файлов;
- новый рапорт формируется как отдельная копия утверждённого шаблона для ручной
  загрузки на закрытый сайт;
- пользовательское `.oxt`-расширение подключает функции ядра непосредственно к Calc.

Собственный Excel/Calc-подобный интерфейс, Univer Sheets и SQLite как первичное
хранилище больше не являются целевой архитектурой.

## PIVOT-001

Первый срез умеет:

1. читать лист `ЖС` без изменения исходной книги;
2. проверять числовые даты и время Excel;
3. воспроизводить подтверждённое окно рапорта `07:00–07:00` и фильтр VBA;
4. заполнять только лист `Аварийные отключения ЛЭП` в копии нового шаблона;
5. формировать `event-selection.csv` и `validation.json`;
6. строго разбирать контракт быстрого ввода дат и времени, включая массовую
   вставку и переход через полночь.

Пример запуска:

```powershell
shift-helper build-emergency-report `
  --journal "Журнал событий актуальный 2026!.xlsx" `
  --template "Рапорт НСС Кочубеевская ВЭС от 2026-07-30.xlsx" `
  --report-date 2026-07-30 `
  --output "Рапорт НСС Кочубеевская ВЭС от 2026-07-30.generated.xlsx" `
  --diagnostics diagnostics
```

## UNO-001

Пользовательское расширение Calc собирается командой:

```powershell
python scripts/build_calc_extension.py
```

Результат:

```text
dist/Shift-Helper-Calc-UNO-001.oxt
```

Автоматический режим обрабатывает быстрый ввод в столбцах `B/C/I/J` листа `ЖС`.
Одиночный ввод сохраняется listener-механизмом до распознавания Calc.

Массовая одноколоночная вставка через `Ctrl+V` в поддерживаемых столбцах
перехватывается через `XKeyHandler`: расширение читает исходный текст из системного
буфера обмена и записывает нормализованный диапазон самостоятельно, до штатного
разбора Calc. Многоколоночная вставка не перехватывается.

Реальные рабочие книги, письма, базы, ФИО и оперативные данные запрещено
публиковать в репозитории.

# Shift-Helper

Локальное кроссплатформенное приложение для ведения рабочих журналов и подготовки сменного рапорта Кочубеевской ВЭС.

## Целевой режим эксплуатации

- одна кодовая база;
- отдельные переносимые сборки для Windows x64 и Linux x64;
- запуск без установщика и прав администратора;
- локальный веб-интерфейс, доступный только через `127.0.0.1`;
- локальная база SQLite;
- основная работа без подключения к интернету;
- экспорт рабочих журналов и рапорта в `.xlsx` с сохранением утверждённого формата;
- подключаемые адаптеры импорта файлов и почты.

## Основные модули

1. Журнал событий.
2. Журнал работ по нарядам и распоряжениям.
3. Утренний рапорт на 07:00.
4. Справочник кодов ошибок ВЭУ.
5. Ведомость замены предохранителей ТН.
6. Осмотры КТП.
7. Расчёт нагрузки трансформатора.
8. Импорт, экспорт и резервное копирование.

## Статус

Проект находится на стадии формирования технического каркаса и первого вертикального прототипа.

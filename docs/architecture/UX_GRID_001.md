# UX-GRID-001 — spreadsheet workspace core

Статус: реализация

Цель — заменить временную самописную contenteditable-таблицу полноценной локальной spreadsheet-сеткой, сохранив структуру исходного журнала событий.

## Обязательный контракт

- журнал занимает доступную высоту рабочего окна;
- визуально непрерывная сетка с запасом пустых строк;
- пустые строки не создают записи в SQLite до ввода данных;
- изменение ширины и порядка колонок сохраняется локально;
- выравнивание задаётся по колонкам и может меняться пользователем;
- закреплены номер строки и ключевые начальные колонки;
- диапазоны выбираются мышью и клавиатурой;
- копирование и вставка совместимы с Excel/Calc через TSV;
- общий поиск и фильтры по колонкам;
- автоподстановка оборудования, исполнителей, авторов и ранее использованных значений;
- дата, время, `!`, `.`, компактный ввод и автозаполнение обрабатываются до сохранения;
- сохранение записи выполняется без кнопок создания;
- структура пользовательского листа не меняется без явного согласования.

## Техническая основа

- Tabulator, закреплённая версия 6.5.2;
- библиотека поставляется внутри переносимой сборки, без CDN во время эксплуатации;
- серверные API и SQLite остаются источником истины;
- настройки раскладки хранятся отдельно от оперативных данных.

# UNO-001 — пользовательское расширение LibreOffice Calc

Status: **IMPLEMENTATION CANDIDATE / MANUAL RUNTIME TEST REQUIRED**  
Issue: `#9`  
Base: `main` / `d361ff0a108a762fd4d410c0af8fc8a2967b5d8c`

## Решение

Первый адаптер LibreOffice выполняется **внутри процесса Calc** как пользовательское
Python-расширение `.oxt`.

Это исключает зависимость переносимого `Shift-Helper.exe` от ABI `pyuno` конкретной
установки LibreOffice. Расширение получает текущий документ через `XSCRIPTCONTEXT`,
а переносимый EXE сохраняется как самостоятельный режим генерации рапорта.

Установка выполняется для текущего пользователя через `Сервис → Расширения` и не
требует прав администратора.

## Состав первого среза

Расширение экспортирует три макроса:

- `show_status` — показывает версию, активный лист и выделение;
- `normalize_selected_dates` — обрабатывает вертикальное выделение в `B` или `I`;
- `normalize_selected_times` — обрабатывает вертикальное выделение в `C` или `J`.

Поддерживаются ранее принятые токены быстрого ввода:

- даты: `.`, `!`, `+N`, день месяца, `DDMM`, `DDMMYY`, полная дата;
- время: `.`, `!`, `+N`, час, `HMM`, `HHMM`, время через двоеточие;
- последовательная обработка многострочного вертикального выделения;
- строгий отказ от невозможных дат и времени;
- переход времени через полночь с увеличением парной даты `B` или `I`.

Ошибочный токен не перезаписывается. После обработки Calc показывает итог и адреса
ошибок/предупреждений.

## Граница безопасности

- расширение не обращается к сети;
- расширение не содержит рабочих книг или оперативных данных;
- обрабатывается только активный лист `ЖС`;
- строка заголовков не изменяется;
- многоколоночное и разорванное выделение отклоняется;
- формулы не используются как предыдущие дата/время;
- изменения объединяются в один undo-контекст, когда LibreOffice предоставляет
  `XUndoManager`;
- сохранение книги остаётся явным действием оператора.

## OXT payload

CI формирует `Shift-Helper-Calc-UNO-001.oxt` со следующим минимальным составом:

```text
META-INF/manifest.xml
description.xml
Scripts/python/shift_helper_calc.py
Scripts/python/pythonpath/shift_helper/__init__.py
Scripts/python/pythonpath/shift_helper/core/__init__.py
Scripts/python/pythonpath/shift_helper/core/quick_input.py
Scripts/python/pythonpath/shift_helper/uno_adapter/__init__.py
Scripts/python/pythonpath/shift_helper/uno_adapter/calc_selection.py
```

Сборщик проверяет безопасные пути, обязательные файлы, регистрацию
`application/vnd.sun.star.framework-script`, экспорт макросов, синтаксис всех
Python-файлов и детерминированность архива.

## Ручная проверка Windows / LibreOffice

1. Установить `.oxt` только для текущего пользователя.
2. Перезапустить LibreOffice.
3. Открыть копию рабочего журнала и лист `ЖС`.
4. Запустить `show_status` через `Сервис → Макросы → Выполнить макрос`.
5. Ввести тестовые токены в копии строк столбца `B`, выделить их вертикально и
   запустить `normalize_selected_dates`.
6. Повторить для `C` через `normalize_selected_times`.
7. Проверить одиночный ввод, многострочную вставку, ошибочный токен и переход
   `23:50` + `+20` с увеличением даты.
8. Проверить один шаг Undo и сохранение/повторное открытие книги.

## Не входит в UNO-001

- автоматический listener на каждое изменение ячейки;
- кнопки/пункты меню Shift-Helper;
- генерация рапорта из Calc;
- импорт генерации из почты;
- очистка legacy Flask/SQLite;
- журнал работ.

Автоматический listener допускается только после отдельного runtime-probe: нельзя
подменять событие изменения текущим выделением без доказательства корректности для
Enter, Tab, мыши и массовой вставки.

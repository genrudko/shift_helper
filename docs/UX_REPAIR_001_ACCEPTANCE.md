# UX-REPAIR-001 — контракт проверки

## Цель

Проверить, может ли локальный веб-интерфейс сохранить скорость и привычную структуру Excel-журнала событий.

## Обязательные свойства

- основной экран представляет собой одну плотную таблицу;
- порядок рабочих колонок соответствует исходному листу;
- отсутствуют кнопки «Новое событие» и «Добавить строку»;
- внизу постоянно находится строка, готовая к вводу;
- дата и время новой строки подставляются автоматически;
- строка создаётся после заполнения даты, времени, оборудования и описания;
- после создания появляется следующая рабочая строка;
- существующие записи редактируются в ячейках;
- заполнение даты и времени пуска завершает событие;
- простой рассчитывается автоматически;
- Tab перемещает вправо, Enter — вниз;
- `!` подставляет текущую дату или время;
- `.` копирует значение из строки выше;
- поддерживается базовая вставка TSV-диапазона из Excel/Calc.

## Не является принятым окончательно

UX-REPAIR-001 — проверочный вариант. Высота строк, ширины колонок, порядок сохранения, поведение клавиш и состав видимых полей подлежат корректировке после практического теста оператором.
